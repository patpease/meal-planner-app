# Meal Planner (retired)

This was the Pease family's first meal planner (React + Dexie, on GitHub
Pages). It was **retired on 2026-11-18**: everything (recipes, photos, pantry,
store choices and meal history) moved to **Pease Meals**
([`patpease/pease-meals`](https://github.com/patpease/pease-meals)).

The code is kept here, read-only, for reference. The GitHub Pages deploy
workflow has been removed, so pushes no longer publish the site.
